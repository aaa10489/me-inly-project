# THE DESERT ADVENTURE
## An interactive 2-minute-45-second sound story

The website is built with your six uploaded nighttime desert / Land Rover Defender photographs. It has a cinematic intro, an interactive FM radio, time-synchronized scene transitions, sand animation, interactive footprints in the exterior scene, a dramatic static flash, and a SIGNAL LOST ending.

## RUN THE PROJECT
1. Unzip the folder.
2. Double-click `index.html` to open the site, or use VS Code > Live Server. It also works on GitHub Pages.
3. Click **START JOURNEY**. The 2:45 experience runs with basic synthesized demo sounds, even if no audio is installed.
4. Set the radio volume, click TUNE, and move the cursor through the outdoor scene to reveal footprints.

## IMPORTANT — ORIGINAL RECORDINGS ARE STILL REQUIRED
This ZIP contains NO original group audio recordings because none were uploaded. The sound-design demo uses generated tones/noise and **does not fulfill the original-audio requirement**. To finish the assignment:
- Edit and layer your actual recorded dialogue, car sounds, desert sounds, footsteps, knocks, radio effects and sourced sounds in Audacity, GarageBand, Adobe Audition, Reaper, etc.
- Export a single final mix, **2:45 long**, as MP3 at `audio/final-mix.mp3`. This is the easiest route for publishing on GitHub Pages.
- Or use **ADD YOUR FINAL MIX** at the bottom of the website to select and test a WAV or MP3 locally. Files picked from your computer won't be uploaded to GitHub automatically.
- When a final mix is loaded, the website follows audio playback time instead of its demo clock.
- The website shows dialogue as on-screen text, but actual human dialogue must be part of your recorded mix.
